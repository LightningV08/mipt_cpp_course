# Лекционное ДЗ №1

Сборка через CMake из папки `lecture_hw1` (C++17):

```sh
cmake -S . -B build
cmake --build build
```

Запуск на Linux/macOS: `./build/task1`, аналогично для остальных задач.
Ввод из консоли или файла: `./build/task1 < input.txt`.

`task1` — дневник погоды. Ввод: N и N целых температур. Вывод: среднее,
минимум и максимум, число дней с отрицательной температурой.

`task2` — копилка. Команды: `deposit k`, `withdraw k`, `balance`, `reset`,
`inc`, `stop`. Дополнительная команда `inc` увеличивает баланс на один рубль.

`task3` — табло 5 × 10. Команды: `clear`, `put x y c`, `text x y word`,
`print`, `quit`. Координаты с нуля: x — столбец, y — строка.

`task4` — карта датчиков со строками разной длины. Ввод: L R Q (слои,
строки в каждом слое, пакеты), затем L строк по R положительных длин.
Ограничения: 1 ≤ L,R ≤ 20, 0 ≤ Q ≤ 1000. Каждый пакет: `i z y` и целые
значения либо `b z y` и маска из 0/1 — по одному значению на ячейку строки.
Индексы z,y с нуля, маска вводится слитно или через пробелы. Ввод корректный.
Пакеты заменяют строки по порядку. Выводится итоговая карта по слоям,
строки без пакетов остаются нулевыми.
